# README全面アップデート（転職活動用）

## Context

前回のREADME更新（gpt-4o-mini移行時）以降、大きな機能追加が複数入っている一方でREADMEは追随していない。具体的には以下が未反映:

- **ゲームごとのスコア管理**（`Game`モデル、`end_game`/`undo_game`）: 1ゲームずつスコアを記録し、スコアボード・過去ゲーム結果・undo機能を提供
- **サーブレシーブ分析モード**（`ServeReceivePattern`/`Rally`モデル、`new_serve_receive`等）: ラリー単位でサーブ/レシーブの戦術パターンを記録するより詳細な分析モード
- **自動保存・中断機能**（`interrupt`/`restore_autosave`）: 入力途中でも下書きが保存され、再開できる
- **検索オートコンプリート**（`autocomplete`）: 大会名/選手名/対戦相手名の入力候補表示。README現状は「サジェストなし」と明記されており未反映
- **非同期処理の廃止**: README技術構成表は「ActiveJob + Sidekiq」のままだが、実際は2026年2月にコントローラーからの同期呼び出しへ変更済み（worker dyno廃止、Sidekiqは管理画面用の設定のみ残存）
- ER図（Gyazo画像）は開発初期のスキーマで、`games`/`rallies`/`serve_receive_patterns`テーブルが未反映
- 画面遷移図（Figmaリンク）は開発前の設計図で実装と乖離

また、編集機能（`edit`/`update`アクション自体はコードに残存）は現在UI上のリンクが撤去されており実質使われていない一方、削除機能（`show.html.erb`の削除ボタン）は実際に使える状態。「今後実装予定の機能」も#77のロードマップ策定（`plans/77-phase-0-77-1-replicated-twilight.md`）で内容が古くなっている。

ユーザーは転職活動のためにREADMEを最新化したい。ヒアリングの結果、以下の方針で合意済み:
- ER図: Mermaid記法で作り直し、README内に直接埋め込む（画像ホスティング不要、スキーマ変更に追従しやすい）
- 画面遷移図: セクションごと削除（機能紹介GIFで画面遷移は十分伝わるため）
- 新機能の紹介: 「ゲームごとのスコア管理」と「サーブレシーブ分析」の2つを主要機能としてGIF付きで紹介し、「自動保存/中断」「検索オートコンプリート」はテキストのみで機能一覧に追記
- 「分析データの編集・削除機能」セクション: 実質使われていない編集機能は削除し、「分析データの削除機能」として削除機能のみ残す
- 検索機能のGIF（`search.gif`）はオートコンプリート表示を含む形で撮り直す
- 「今後実装予定の機能」セクションは丸ごと差し替え、`plans/77-phase-0-77-1-replicated-twilight.md`のPart 2ロードマップ（Phase 0, 1, 2, 4, 5）を反映する。ただしPhase 3「収益化基盤の導入（課金開始）」は転職用ポートフォリオの範囲外として含めない

## 変更方針

### 1. 目次の更新
- 「画面遷移図」の項目を削除
- 新規セクション（ゲームごとのスコア管理、サーブレシーブ分析）を機能紹介配下に追加

### 2. 機能紹介セクションの更新（README.md 58〜177行目付近）
- 既存の「試合分析機能」テーブルはそのまま維持（`new.gif`/`show.gif`は現行フローと一致していることを確認済み）
- 新規テーブルを2つ追加:
  - **ゲームごとのスコア管理機能**: ゲーム終了時に技術別得点を記録しスコアボードが更新される様子、undo操作 → GIF撮影が必要（ユーザー側で用意）
  - **サーブレシーブ分析機能**: サーブ/レシーブのパターンを記録して分析する様子 → GIF撮影が必要（ユーザー側で用意）
  - 画像ファイル名は例: `game_scoring.gif`, `serve_receive.gif`（ユーザーが`app/assets/images/`配下に配置）
- 「分析データの編集・削除機能」テーブルを「分析データの削除機能」に変更: 編集機能の列・GIF(`edit.gif`)・説明文を削除し、削除機能(`delete.gif`)のみの単一カラムテーブルにする（UI上に編集への導線がなく実質使われていないため）
- 「分析データ検索機能」テーブルの見出しを「分析データ検索機能」に変更（「(サジェストなし)」を削除）、説明文にオートコンプリート対応を追記。GIF(`search.gif`)はオートコンプリートの候補表示が写る内容に撮り直す（ユーザー側で用意）
- 自動保存/中断機能はGIFなしで、新規の短いテキスト説明（見出し + 1〜2文、機能紹介セクションの末尾に追加）として追加

### 3. 今後実装予定の機能セクションの更新（179〜196行目）
セクション全体を`plans/77-phase-0-77-1-replicated-twilight.md`のPart 2ロードマップに差し替える。実装済みになった既存の3項目（サーブレシーブ分析、得点板表示、検索オートコンプリート）は自然に消える。新しい内容は以下を簡潔に和文でまとめる（技術実装の詳細ではなく、ユーザー視点でどう嬉しいかを中心に記述）:
- **Phase 0: データ集計基盤 ＋ 成長ダッシュボード** — 複数試合をまたいだ技術別得点率の月別/週別推移グラフ
- **Phase 1: 対戦相手タイプ別分析** — カットマン/ドライブ型などタイプ別の勝率・技術別得点率分析
- **Phase 2: AI長期メモリ ＋ 月間成長レポート** — 過去のアドバイスを踏まえた継続的なコーチング、練習メニュー提案
- **Phase 4: 用具データ連携** — ラケット/ラバー変更前後の比較分析
- **Phase 5: コミュニティ機能** — 成長記録の共有、クラブ/ランキング機能

Phase 3「収益化基盤の導入（課金開始）」はビジネス戦略の詳細であり転職用ポートフォリオの範囲外として掲載しない。
